About SignBridge AI

Communication without barriers.

The problem

Deaf and hard-of-hearing students in Gujarat face a real communication gap in classrooms and daily life. Existing accessibility tools are scarce, expensive, or don't support Gujarati alongside English and Indian Sign Language (ISL) — leaving a language gap on top of the hearing gap.

Our solution

SignBridge AI connects teachers and students through all three languages in one platform: live speech-to-sign translation in the classroom, a standalone sign converter and simplifier, a six-category sign dictionary with adaptive quizzes, two-way communication for quick questions, and a dashboard that tracks each student's weak signs for personalised practice.

Tech stack

Frontend

HTML, CSS, vanilla JavaScript

Backend

Python Flask

Database

SQLite

Speech

Browser Web Speech API

AI Layer

Modular rule-based engine, with an optional LLM hook

A note on the sign images

Every sign in this MVP is shown with a real generated illustration file (not an emoji), served from static/signs/images/, exactly where verified ISL video or photo assets would go in a production build. They are clearly-labelled placeholders because sourcing a verified ISL video library for 70+ words was out of scope for a hackathon build — swapping in real assets requires no code changes, just dropping files into that folder.
